## Study rules

- Commit at end of every session. Message style: `log: 2026-11-20`, `notes(F01): induction`, `dsa(two-pointers): 3sum`.
- Every Saturday update the table, then `git tag week-01 && git push --tags`.
- AI may quiz, check a proof, or explain an error, but never writes a solution or note.
- If AI helped, add [ai-review] to the note.
